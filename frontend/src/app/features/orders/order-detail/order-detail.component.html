API trace

Calls behind this screen

  • GET /api/orders/{{ order.id }} Loads the order; ownership is enforced in the service.
  • GET /api/orders/{{ order.id }}/documents Lists attachments through the authenticated document endpoint.
  • PATCH /api/orders/{{ order.id }}/submit NEW → SUBMITTED. Owner or administrator.
  • PATCH /api/orders/{{ order.id }}/approve SUBMITTED → APPROVED. ADMIN only.
  • PATCH /api/orders/{{ order.id }}/reject SUBMITTED → REJECTED with a reason. ADMIN only.
  • PATCH /api/orders/{{ order.id }}/cancel NEW or SUBMITTED → CANCELLED. Owner or administrator.
